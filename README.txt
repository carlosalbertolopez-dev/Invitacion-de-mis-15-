CÓMO PROBAR
1. Descomprime la carpeta.
2. Agrega un MP3 propio dentro de audio y llámalo musica.mp3.
3. Abre index.html en el navegador para probar el diseño.
4. Para compartirlo con invitados, publícalo en un hosting estático (por ejemplo GitHub Pages o Netlify) y comparte la URL pública.

CONFIRMACIÓN POR WHATSAPP
El número de destino está configurado en js/script.js como 573147324674 (Colombia).
Al enviar el formulario, se abre WhatsApp con el texto ya escrito. El invitado debe tocar Enviar en WhatsApp.
Una página HTML estática no puede mandar mensajes de WhatsApp automáticamente ni almacenar las respuestas por sí sola.
Si necesitas que las respuestas se guarden automáticamente o se envíen sin intervención del invitado, se necesita un backend y una integración oficial de WhatsApp Business Platform.
